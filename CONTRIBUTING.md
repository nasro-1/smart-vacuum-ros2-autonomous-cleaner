# Contributing

This repository is primarily an academic robotics project.

Before submitting changes:

1. Preserve the ROS 2 package structure.
2. Do not commit `build/`, `install/`, or `log/`.
3. Do not commit credentials, API keys or private data.
4. Keep experimental research modules clearly separated from the active baseline.
5. Explain how ROS 2/Gazebo changes were tested.
6. Update documentation when launch procedures or dependencies change.
